# Comparateur de coût véhicule

Objectif réel : apprendre à déployer un outil simple, du code à une URL publique.
Objectif apparent : comparer le coût de détention sur 5 ans de plusieurs véhicules.

## Périmètre figé — ne pas élargir
- Pas de base de données
- Pas de comptes utilisateurs
- Pas d'appel à une API externe
- Pas de paiement
Toute idée d'ajout va dans une liste "plus tard", jamais dans le code.

## Façon de travailler
- Expliquer chaque commande avant de l'exécuter, je veux comprendre.
- Ne pas écrire de gros blocs de code sans que je les lise et les valide.
